# Code of Conduct

We want this project to be a friendly, harassment-free space for everyone.

**Expected:** be respectful, welcome newcomers, give and accept constructive feedback, and focus on what helps the project.

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing others' private information, or other conduct that would be inappropriate in a professional setting.

Maintainers may remove comments, commits or contributions that break these rules, and may ban repeat offenders. Report problems to the maintainer through the contact listed on the repository profile.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
