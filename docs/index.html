Quick start

From clone to cluster in one command

Needs a Mac, Docker Desktop or OrbStack with about 8 GB of RAM, and Homebrew. The script installs the rest.

  1. Set up

    Creates the cluster, installs the tools and connects ArgoCD. The first run takes roughly 15 to 20 minutes.

  2. Open the tools

    URLs and logins are printed at the end of every command, with live UP or DOWN status.

  3. Stop and start daily

    lab stop in the evening, lab start in the morning. Nothing is lost.

  4. Verify

    lab verify shows what runs in Docker and what runs in the cluster.

terminal
# first time
$ git clone __REPO_URL__ devops-lab
$ cd devops-lab && ./lab.sh up

# every day
$ lab start
$ k9s
$ lab stop

FAQ

Common questions

Which Kubernetes distribution does it use?

kind (Kubernetes in Docker). It is lightweight, starts quickly and rebuilds in minutes, which suits personal experiments on a laptop.

Does it run on Apple Silicon?

Yes. It is built for M-series Macs and uses arm64 images throughout.

Where does Jenkins run, and where is its data?

Jenkins runs in its own Docker container outside the cluster. Its files are mirrored to a local jenkins_wp folder, so you can browse them without logging into the container.

Is my data kept when I stop the lab?

Yes. lab stop keeps everything. lab destroy removes the cluster and the Jenkins container but keeps jenkins_wp; add --purge to wipe that too.

Is it safe to use these default passwords?

Only on localhost. Every port is bound to 127.0.0.1, but the default passwords are public, so never reuse them or expose the lab to a network.
